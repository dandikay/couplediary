Kebijakan Privasi – Couple Diary

Terakhir diperbarui: 9 November 2026

Couple Diary adalah aplikasi pribadi untuk pasangan menyimpan catatan, rencana, dan foto bersama. Halaman ini menjelaskan data apa yang dipakai dan bagaimana data itu diperlakukan.

Data yang diakses

Saat login dengan Google, aplikasi menerima alamat email dan ID akun Google Anda. Aplikasi juga meminta izin drive.file, yaitu akses hanya ke file yang dibuat oleh aplikasi ini di Google Drive Anda. Aplikasi tidak dapat melihat atau mengubah file Drive Anda yang lain.

Data yang disimpan

  • Di Google Drive Anda: folder "Couple Diary" berisi data.json (catatan, rencana, kenangan) dan foto yang Anda unggah.
  • Di server aplikasi: alamat email, username, hash password (bukan password asli), dan token akses Google yang dienkripsi. Data ini dipakai hanya untuk menjaga sesi login.

Penggunaan dan berbagi

Data hanya dipakai agar aplikasi berfungsi. Data tidak dijual, tidak dibagikan ke pihak ketiga, dan tidak dipakai untuk iklan atau pelatihan model AI.

Menghapus data

Anda dapat menghapus folder "Couple Diary" dari Google Drive kapan saja, dan mencabut akses aplikasi di myaccount.google.com/permissions. Untuk menghapus data akun di server aplikasi, hubungi kontak di bawah.
